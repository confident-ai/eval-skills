# Sources and acknowledgments

This suite's prose and helpers are original. Its workflow is informed by human-led error analysis, evaluator calibration, and controlled software experimentation.

- [Hamel Husain and Shreya Shankar's evals-skills](https://github.com/ai-evals-course/evals-skills): observed failure modes, useful human review interfaces, and judge validation.
- The user-provided “Building an Eval for a Claude-Powered Application” and “Hill-Climbing on an Eval” guides: evidence-linked runs, experiment records, and bounded improvement loops. Their text and unpublished supporting scripts are not redistributed here.
- [Confident Trace](https://github.com/confident-ai/confident-trace): current Python/TypeScript tracing APIs and content controls.
- [Confident AI documentation](https://www.confident-ai.com/docs): hosted datasets, annotation workflows, evaluation, and monitoring.
- [Confident Actions](https://github.com/confident-ai/confident-actions): hosted PR evaluation gate integration.
- [DeepEval](https://github.com/confident-ai/deepeval): optional local grading integration.
- [Agent Skills](https://agentskills.io): portable skill packaging.

Integration references were reviewed on 2026-09-30. They are not a guarantee that every SDK version or account exposes every capability. Resolve actual supported versions and tools during setup.

The repository banner is newly generated artwork. Existing Confident Trace and Confident Actions banners supplied style references. The SVG wrapper is an original implementation of the same four-second reveal treatment.
